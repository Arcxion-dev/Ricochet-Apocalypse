Ricochet-Apocalypse · Unity 6000.3.18f1 · 2D · Legacy Input Manager · URP

이번 작업: 스테이지 클리어 흐름을 **클리어 UI → 상점 → 다음 스테이지(준비/시작)** 로 재구성. 클리어 보상 **드랍테이블** 시스템과, 스테이지 진입 시 **준비(Ready) 상태**(조준 차단) + [시작]/[상점] 버튼을 추가.

> 결론 요약: 클리어 시 골드+드랍테이블 아이템을 지급하고 **StageClearUI**(부트스트랩 싱글턴)로 결과를 띄운다. [확인]→상점. 클리어 시점에 스테이지 인덱스를 **미리 전진**시키고 상점 '출발'은 `LaunchCurrentStage()`로 그 준비된 스테이지를 연다(준비 상태에서 상점을 다녀와도 같은 스테이지로 복귀). 모든 스테이지는 **StageReadyUI** 준비 상태로 시작하며, `GameManager.StageStarted`가 false인 동안 **PlayerShooter가 조준/격발을 막는다**.

## 입력한 프롬프트 (원문, 시간순)

1. "푸쉬했고 이제 스테이지 클리어 UI(보상 드랍테이블, 상점창 연결)을 만들거야. 스테이지가 클리어되면 클리어 UI창이 뜨고 확인버튼을 누르면 상점으로 이동, 상점에서 다음 스테이지로 이동하되, 다음스테이지에서 준비/시작 두 상태로 구분하고 준비 상태면 상점 UI를 눌러 다시 상점을 이용할 수 있도록 해. 스테이지 준비에서 시작은 시작버튼을 따로두고 준비상태때는 조준이 일어나지 않도록 막아"
2. (질문 응답) 드랍테이블 → "실제 아이템 드랍테이블" / 첫 스테이지 → "모든 스테이지 준비상태"
3. "작업일지 작성하고 커밋해. 일단 드랍은 골드만 드랍되는걸로 해놨어"

## 요청과 처리

### 1) 드랍테이블 시스템
- 신규 `Assets/Scripts/Stage/DropTableSO.cs`(+`DropResult` 구조체): 항목별 독립 확률(chance)로 굴려 min~max 수량을 지급.
  `Create > Stage > Drop Table`로 에셋 생성. 스테이지별로 `Resources/DropTables/{씬이름}.asset`(없으면 `Default`)을 두면 자동 사용.
- `GameManager.RollAndAwardDrops()`가 현재 씬 이름으로 테이블을 로드해 굴리고 인벤토리에 지급, 결과를 클리어 UI로 넘김.
- 골드는 기존 점수 공식으로 별도 지급되고 드랍표는 그 위에 아이템을 얹음.
- 샘플 `Resources/DropTables/Default.asset` 생성(현재는 사용자가 **골드만**(20~50) 드랍하도록 조정).

### 2) 스테이지 클리어 UI
- 신규 `Assets/Scripts/UI/StageClearUI.cs`: 부트스트랩 싱글턴 오버레이(코드 생성 uGUI). 결과 요약(퍼펙트/콤보/처치/발사)·획득 골드·드랍 아이템 목록 표시, [확인] 콜백 실행.
- `GameManager.StageClear()`가 즉시 상점 이동 대신 **드랍 지급 → StageClearUI.Show(...) → [확인] 시 ProceedAfterClear**로 변경.

### 3) 준비/시작 상태 + 조준 차단
- 신규 `Assets/Scripts/UI/StageReadyUI.cs`: 부트스트랩 싱글턴. 스테이지 씬 진입 시 하단 "준비" 패널 표시([상점]/[시작]). [시작]→`GameManager.StartStage()`+닫기, [상점]→`SceneLoader.LoadShop()`.
- `GameManager`: `StageStarted` 상태 + `StartStage()`/`SetStageReady()`. `ResetStageState`에서 false로 초기화(모든 스테이지 준비 시작). 클리어 순간에도 false로 되돌려 클리어 창 뒤 사격 방지.
- `PlayerShooter.Update`: UI 정지 체크 다음에 `!StageStarted`면 조준선 숨기고 격발/아이템/변경/호흡 입력을 모두 차단.

### 4) 상점 경유 & 스테이지 인덱스 시맨틱 변경
- 기존: 상점 '출발'이 `LoadNextStage()`로 인덱스를 전진.
- 변경: **클리어 시점에 인덱스를 전진**(`ProceedAfterClear`)하고, 상점 '출발'과 준비→상점 복귀는 `SceneLoader.LaunchCurrentStage()`(=`LoadStage(현재인덱스)`)로 **같은 준비된 스테이지**를 연다 → 준비 상태에서 상점을 다녀와도 중복 전진 없음. 최종 진행 순서는 기존과 동일.
- 마지막 스테이지 클리어 시 `LoadResult()`.

### (병행) 스테이지 재편성 — 사용자 작업
- 사용자가 스테이지 라인업을 재편성(구 Stage3→Stage2 경로, Stage3 신규, Stage4/5 빌드세팅 재등록). `EditorBuildSettings.asset`/`Stage2·3·5.unity`가 함께 커밋됨.

## ⚠️ 교훈 / 비고
- `GameManager`는 DontDestroyOnLoad 싱글턴이라 스테이지별 인스펙터 값을 못 쓴다 → 드랍테이블은 **씬 이름 규칙 Resources 로드**로 스테이지별 지정(인스펙터 의존 없음).
- 클리어/준비 UI는 **부트스트랩 싱글턴 + 코드 생성 uGUI**로 씬 배치 없이 전 스테이지에서 동작(HitFeedbackManager 패턴).
- 스테이지 인덱스 전진 시점을 상점 '출발'→**클리어 시점**으로 옮겨야 준비 상태 상점 재방문이 중복 전진 없이 성립.
