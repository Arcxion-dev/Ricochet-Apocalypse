## 요청과 처리

### 1) 헤드샷 시스템 실작동 + 조준경 재설계 + 텅스텐 파츠
- **핵심 버그**: `HeadshotModule` guid가 어떤 prefab/scene에도 없음 → 헤드샷 절대 미발생. `EnemyController.Awake`에서 없으면 `AddComponent<HeadshotModule>()`로 자동 부착(모든 적 30%/2배 적용).
- `EnemyController.OnBulletHit` 시그니처 확장: `(..., float headshotMultiplierBonus=0, bool forceHeadshot=false)` + `bool`(헤드샷 여부) 반환. forceHeadshot이면 확률 스킵, 헤드샷 시 배수 ×(1+bonus).
- **ScopePartSO 재설계**: 조준선/반사 기여 제거 → `headshotBonus=0.2`(헤드샷 배수 +20%). `WeaponStats`에 `headshotMultiplierBonus`/`guaranteedHeadshotChain` 추가.
- **직선 레이저 기본 상시화**: `PlayerShooter.UpdateLaser`의 `laserEnabled` 게이트 제거.
- **LaserSightPartSO**: `extraBounces` 추가 → 이제 "추가 사거리+반사 예측" 업그레이드(조준경이 갖던 반사 이관).
- **신규 TungstenPartSO**(+`Part_Tungsten.asset`): `PlayerShooter.static Active` + 예약상태(`ArmGuaranteedHeadshot`/`ConsumeGuaranteedHeadshot`). `BulletController.HandleEnemyHit`이 사수 상태를 읽어 확정/보너스 적용, 자연 헤드샷 시 다음 발 예약(확정 헤드샷은 재예약 안 함). 분열 자식탄은 정적 접근이라 자동 커버.
- 배선: **Stage1 PlayerShooter EquippedParts에 Part_Tungsten 추가·저장**(사용자 선택: Stage1만). Stage2/3 미배선.

### 2) 민간인 고정 (`EnemyAIModule`)
- `Awake`에서 `CompareTag("Civilian")` → `isCivilian`. 민간인은 목적지 미설정·`agent.isStopped`(navmesh 위일 때)·Update 최우선 early-return으로 **제자리 고정**. 현재 유일 민간인(WallPrefab_Civilian)은 원래도 정적이라 무변화, 미래 대비 가드.

### 3) 1회용 사용 아이템 3종 + 선택/사용 개편
- **`UsableItemSO`**(`: ItemDefinition`) + `UsableItemKind{Grenade,Airstrike,Flashbang}`. 에셋 `Assets/Resources/UsableItems/Item_{Grenade,Airstrike,Flashbang}.asset`(Item 버킷, 스택9). 값: 수류탄 사거리5/반경2/뎀40, 폭격 12/3.5/60, 섬광 6/3/뎀0/저지3s.
- **입력 개편(모드 토글식, `PlayerShooter`)**: `InputMode{Normal,BulletChange,ItemChange,ItemAim}`. Q=탄환변경, E=아이템변경(휠/좌클릭 순환, 키/ESC/우클릭 종료), F=아이템 사용(범위 원이 마우스 따라감·사거리 클램프 → 좌클릭 확정/우클릭 취소). 숫자키 1~5·좌클릭 발사 유지. **모드/조준 중 카메라 휠 줌·팬 일시 정지**(휠이 순환에 쓰임). 키는 인스펙터 노출.
- 효과 적용: `Physics2D.OverlapCircleAll`(enemyMask=`_bulletPrefab.EnemyLayerMask`)+dedup. 수류탄/폭격=`EnemyController.OnBulletHit(뎀,None)`(없으면 `BulletDamageDispatcher`), 섬광=`ISuppressible.ApplySuppression(3s,1)`. VFX=`EffectHandler.explosionName`.
- **적 이동 저지 실작동**: `EnemyAIModule : ISuppressible`. `ApplySuppression(dur,slow)` → 완전정지(slow≥1)면 `agent.isStopped=true`, 부분 감속은 `SyncSpeed`에서 `speed*(1-slow)`. 저지 분기는 EnemiesCanChase 게이트보다 먼저. **기존 저지탄(`SuppressionEffectSO`)도 이제 작동**(이전엔 구현체 전무).
- **UI**: `ItemInventoryUI` — 좌하단 탄환 HUD 위(margin y=260)에 별도 "아이템" HUD(선택 ▶강조·활성 모드 안내). `InventoryUI`(우상단)에 **＋수류탄/＋폭격지원/＋섬광탄** 디버그 버튼.
