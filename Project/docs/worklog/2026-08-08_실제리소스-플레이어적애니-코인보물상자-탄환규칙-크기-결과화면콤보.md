## 배경 / 발견
- `Assets/Resources/실제 사용할 리소스/`에 최종 아트가 새로 들어옴(플레이어 시트, EnemySprite 12종, Coin/보물상자 스프라이트 에셋).
- **적 시각 시스템이 이중**이었음: (1) 스테이지의 실제 적은 `Enemy_*.prefab` 인스턴스, (2) 별개로 `ShapeModule` 색상 사각형/무비주얼 버전도 존재. 스테이지 적은 프리팹 인스턴스라 **프리팹 에셋을 직접 배선하면 전 스테이지 반영**됨.
- 플레이어 시트는 단일 프레임이 아니라 **스프라이트시트**(프레임 흩어짐, 시트마다 해상도 다름). Unity 자동 슬라이스 API가 이 버전에서 0개 반환 → **직접 픽셀 블롭검출로 슬라이스**.

## 처리

### 플레이어 애니메이션
- 5개 시트(idle/aiming/fire/move(L)/move(R)) 블롭검출 슬라이스 + **시트별 PPU 정규화**(NPOT 스케일 OFF·최대텍스처4096로 치수 고정). `player/Player.controller` 생성(파라미터 IsMoving/MoveX/IsAiming/Fire, 상태 Idle/Move_L/Move_R/Aiming/Fire, AnyState→Fire), `Player.prefab` Visual에 Animator 배선.
- 코드 훅: `PlayerMovement`(IsMoving/MoveX), `PlayerShooter`(EnterBreath/ExitBreath=IsAiming, TryFire=Fire 트리거).
- **조준 크기 보정**: 조준 포즈는 소총을 세로로 든 뒷모습이라 프레임 바운딩박스에 세로 소총이 포함 → 높이정규화 시 몸이 작아 보임. 조준 시트 PPU 680→504(≈1.35배)로 몸 크기를 idle/move에 맞춤.

### 적 애니메이션 (속성별 직접 배선)
- EnemySprite 12종을 **블롭검출로 직접 재슬라이스**(후처리 병합 금지 — 인접 프레임이 촘촘히 붙어 병합하면 run/summon이 1~2프레임으로 붕괴). 프레임수: base6·armory8·run6·shield6·summon6·haste6·ice14·stealth8·magnetic6·obstacle6·electric6·flame6.
- idle/move 클립을 새 슬라이스로 채움(LIVE `Prefabs/Enemies/Animations_Enemy/Enemies/*.anim` in-place, 컨트롤러 GUID 참조 보존).
- 11개 `Enemy_*.prefab` 각각 매칭 오버라이드 컨트롤러 + idle 스프라이트 배선(Fire→화염, Ice→얼음, Electric→전기, Armored→갑옷, Haste→신속, Stealth→은신, Magnet→자석, Shield→방패, Summon→소환, Flee→도망, Base→일반). Stealth/Magnet/Shield/Summon/Flee는 Visual이 없어 새로 생성. `EnemyAIModule`이 NavMeshAgent 속도로 IsMoving 구동. (Split/Teleport/Corpse·obstacle시트는 대응 없음 → 제외)
- **폐기**: `EnemyVisual` 자동부착 방식은 모든 적을 기본 Base로 덮어써 매칭을 파괴 → 삭제하고 프리팹 직접 배선으로 전환.

### 적 크기 (1.4유닛)
- 각 프리팹 Visual SR 스케일을 `1.4/(최대면적프레임높이 × 부모lossyScale)`로 설정. **함정**: 적 Visual 계층에 부모 스케일 0.5가 있어 처음엔 0.7유닛으로 나옴 → 부모 lossyScale 보정. 콜라이더(BoxCollider2D)는 스프라이트에 맞춰 1.4×1.4(콜라이더 2배는 NavMesh 통로 막힘 위험이라 제외).
- ice: 사용자가 에디터에서 재슬라이스 → 프리팹 default 스프라이트가 사라진 `ice_idle_0`을 가리켜 **null(빈 프레임)**. 클립을 현재 서브(각 6프레임)로 재생성 + default 스프라이트도 현재 첫 프레임(`ice_idle_5`)으로 갱신.

### 코인 / 보물상자
- 코인: `Resources/Currency/Gold.asset`(ItemDefinition).icon = `Coin.asset`, StageHud 프리팹 GoldPanel/Coin 이미지 + `StageHudPrefabBuilder.BuildGold`도 Coin 로드.
- 보물상자(구 민간인 `WallPrefab_Civilian.prefab`): 스프라이트 `보물상자_코인.asset`. 탄환 피격 시 **관통(반사X, 일반 몹과 동일) + 파괴 + `GameManager.OnTreasureChestHit()` +50골드**. 기존 민간인 골드차감 페널티(OnCivilianHit/_civilianHitPenalty/DebugCivilianHit) 삭제. Destroy 지연에 의한 중복보상은 `_lastPenetratedWall` 가드로 방지.

### 탄환 규칙
- 철갑탄 반사: `BulletController.DetermineHitResult`에 조기반환 추가 → 철갑탄은 **ArmoredWall(철갑벽)에서만 반사, 그 외(나무/바위/일반벽/전자패널) 전부 관통**. 실제 탄환·조준 가이드라인 공유 함수라 자동 일치. 비철갑탄은 기존 유지.

### 결과화면 콤보 코인 표시
- `StageResult`에 `ComboBonus`(=_rewardPerCombo×_bestCombo) 추가, `StageClear`에서 전달. `StageClearUI._goldBreakdown`(결과 프리팹 GoldBanner/Break 라벨 바인딩)에 "콤보 ×N 보너스 + M G" 출력.

## 검증
- 컴파일 에러 0(`assets-refresh`).
- 프리팹 인스턴스 렌더로 속성별 적이 고유 스프라이트로 나옴 확인(화염/얼음/전기/방패/은신/자석/소환/갑옷 등), 크기 worldH≈1.40, ice 빈 프레임 없음.
- 철갑탄 규칙 정적 함수 직접 호출 검증(AP: ArmoredWall=Bounce, 그 외=Penetrate / 일반탄=기존).
- 결과화면 플레이 검증: `획득 골드 +275 G` 아래 `콤보 ×3 보너스 + 75 G` 표시.
- 조준/idle/move 나란히 렌더로 조준 몸 크기 일치 확인.
