Ricochet-Apocalypse · Unity 6000.3.18f1 · 2D · URP

브랜치: `feat/stagehud-persistent-play-label` (메인에서 작업하던 것을 이 브랜치로 분기해 커밋).

## 원인
- 프로젝트 전체에 **적이 플레이어에게 피해를 주는 코드가 아예 없었다.** `EnemyAIModule`은 추격만 하고, `Player.TakeDamage`를 호출하는 곳이 어디에도 없음.
- 게다가 플레이어(layer 6 "Player", BoxCollider2D 0.8², 비트리거)와 적(layer 7 "Enemy", BoxCollider2D 비트리거) **둘 다 Kinematic Rigidbody2D** → Unity 2D는 Kinematic↔Kinematic + 비트리거 조합에서 `OnCollision`/`OnTrigger` 콜백을 발생시키지 않는다. 그래서 콜백 방식으로는 접촉 감지 자체가 불가.

## 처리
- `Player.cs`(=Entity 서브클래스, 모든 스테이지의 Player에 존재)에 접촉 피해 로직 추가. 씬/프리팹 편집 없이 40개 스테이지 전부 커버.
- `FixedUpdate`에서 플레이어 콜라이더의 `Collider2D.Overlap(ContactFilter2D, buffer)`로 매 물리 프레임 겹침을 직접 질의 → 'Enemy' 태그 대상과 접촉 시 `TakeDamage`.
- 무적 시간(`_invulnerabilitySeconds`, 기본 1s)으로 겹친 동안 매 프레임 깎임 방지.
- `GameManager.EnemiesCanChase`가 켜진 뒤(스테이지 실제 진행 중)에만 피해 → 스폰 직후 겹침 즉사 방지.
- 민간인(Civilian) 태그 제외. 피해량/무적/레이어는 인스펙터 노출(기본 10 / 1s / "Enemy").
- HUD는 `Entity.OnDamaged`를 폴링(StageHud)해 체력바/플래시 자동 반영 → 별도 연출 코드 불필요.

## 검증 (플레이모드, script-execute)
- 물리 팩트 확인: Player/Enemy 둘 다 Kinematic·비트리거 → Overlap 방식이 정답. Enemy tag=Enemy, layer=7(mask 128 = `LayerMask.GetMask("Enemy")`), 플레이어 BoxCollider2D 0.8² 확인.
- 적을 플레이어 위에 고정 + `EnemiesCanChase` 강제 ON → 체력 **100→20→사망**. 사망 시 `Player.FixedUpdate → TakeDamage → DecreaseHP → GameManager.OnPlayerDeath → SceneLoader 스테이지 재시도`까지 정상 로그 확인.
- 컴파일 에러 없음. 검증 위해 플레이모드를 잠깐 껐다 켰고(스크립트 컴파일 목적), 테스트 중 사망→스테이지 리로드로 save.json이 자동저장으로 갱신됨(게임 진행 데이터라 무해).
