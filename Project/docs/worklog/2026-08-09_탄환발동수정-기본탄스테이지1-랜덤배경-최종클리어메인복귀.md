## 1) 폭발탄·중력탄·마비탄 발동 수정
효과 SO 배선·탄환 프리팹 레이어마스크(적=layer7=128, 벽=layer8=256)는 모두 정상이었고, 문제는 순전히 **발동 로직**이었음.
- **폭발탄/중력탄**: 두 효과는 `OnBulletDestroyed`(=Die)에서만 발동했는데, 탄환은 적을 관통하고 **벽 튕김 10회 / 수명 5초** 뒤에야 죽어 엉뚱한 자리에서 뒤늦게 터졌음(사실상 무효). → 둘 다 `OnHitEnemy`에서 **즉시 발동 + `bullet.Kill()`로 그 자리 소멸**(관통 금지)하도록 변경. 적 못 맞히고 벽/수명으로 죽을 땐 기존처럼 `OnBulletDestroyed`에서 발동(폭발탄 바위 파괴 유지). 중복 발동은 `bullet.HasTriggeredZoneEffect/MarkZoneEffectTriggered(typeof self)` 가드. `BulletController.Kill()`(public) 신설.
- **중력탄 끌림 무효 원인**: 적은 **NavMeshAgent**로 스스로 이동 → `rb.MovePosition`이 다음 프레임 에이전트 이동에 덮여 끌려오지 않음. `GravityWellRunner`가 이제 각 적에 `ISuppressible.ApplySuppression(remaining,1)`로 AI를 멈추고 **`NavMeshAgent.Move(step)`**로 중심 쪽으로 실제로 끌어당김(폴백: rb.MovePosition/transform).
- **마비탄(저지탄)**: `SuppressionEffectSO`의 `enemy.GetComponent<ISuppressible>()` → **`GetComponentInParent`**로 변경(자식 콜라이더 적 대비, PlayerShooter 섬광탄과 동일 패턴). Enemy_Base 기준 콜라이더·RB(Kinematic)·NavMeshAgent·EnemyAIModule(ISuppressible)·EnemyController가 모두 루트에 함께 있음.

## 2) 기본탄 스테이지1 한정
- `PlayerShooter.Start()`의 `_startingBullets`(기본탄 로드아웃) 지급을 **`SceneLoader.CurrentStageIndex == 0`(첫 스테이지)일 때만** 실행하도록 게이트. 이후 스테이지는 상점 구매/드랍/회수로만 보급.
- 스테이지 클리어 시 기본탄 지급 경로는 이 `Start()`가 유일(GameManager는 골드·드랍테이블만 지급) → 다른 곳 수정 불필요.

## 3) 스테이지 랜덤 배경
- 스프라이트: `Assets/Resources/실제 사용할 리소스/배경/배경1.png`·`배경2.png`(887×1774px). 원래 Default 텍스처(`textureType:0`)로 임포트돼 있어 `.meta`를 **Sprite**(`textureType:8`,`spriteMode:1`)로 바꿔 재임포트. Resources 경로=`실제 사용할 리소스/배경/배경1`.
- 신규 `Assets/Scripts/Managers/StageBackground.cs`: **씬 배치 없이 부트스트랩 상주**(`[RuntimeInitializeOnLoadMethod(AfterSceneLoad)]`, DontDestroyOnLoad, 런타임 인스턴스 검사 — StageBgm/StageHudBootstrap과 동일 패턴). `sceneLoaded`에서 씬명이 "Stage" 시작이면 **배경1/2 중 랜덤 1개** 표시, 그 외 씬은 숨김. 자식 SpriteRenderer가 **Camera.main을 매 LateUpdate 추종**하며 뷰포트를 cover로 채움(팬/줌 무관). sortingOrder **-200**(타일맵 바닥 -10·맵배경모듈 -100보다 뒤).
- 검증: `Resources.Load<Sprite>` 둘 다 성공(`배경1=True 배경2=True`), 컴파일 무오류.

## 4) 마지막 스테이지 클리어 → 메인 메뉴
- 기존엔 최종 클리어 시 `SceneLoader.LoadResult()`(플레이스홀더 Result 씬). → **기존 `StageClearUI` 재사용**으로 최소 변경.
- `GameManager.StageClear`: `CurrentStageIndex + 1 >= StageCount`이면 최종 스테이지로 보고 클리어 창을 **"게임 클리어" 타이틀 + "메인 메뉴" 버튼**으로 표시. `ProceedAfterClear`는 최종이면 `SceneLoader.LoadTitle()`(인덱스 0 초기화)로 메인 복귀.
- `StageClearUI.Show`에 선택 파라미터 `titleOverride`/`confirmLabel` 추가. `StageClearUI`가 DontDestroyOnLoad 싱글턴이라 라벨이 남는 걸 막으려 **확인 버튼 기본 라벨을 Awake에서 캐시**해 일반 스테이지에서 복원. Result.unity는 이제 미사용(플레이스홀더로 존치).
