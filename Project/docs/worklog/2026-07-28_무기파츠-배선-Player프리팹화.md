## 요청과 처리

### 1) 파츠 역할 문서화 + 반사 가이드라인 파츠 확인
> "각 파츠 역할 문서로 정리하고 … 반사 경로 가이드라인 파츠 구현 확인"

- `docs/무기파츠-정리.md` 작성. 7종 파츠(손잡이/네뷸라이저/강선/조준경/텅스텐/레이저/반사 예측기)의 효과·핵심값·중첩(곱/합) 표 + 집계 구조(`WeaponPartSO.Contribute`→`WeaponStats`→`PlayerShooter.RecomputeParts`) 정리.
- **반사 가이드라인 = 구현되어 있음**을 코드로 확인:
  - `ReflectionSightPartSO.Contribute` → `reflectionEnabled/predictBounces/predictRange` 설정.
  - `PlayerShooter.UpdateLaser`(가이드라인 갱신) → `BuildGuidelinePoints`가 **실제 탄환과 동일 규칙**(`Physics2D.CircleCast` + `Vector2.Reflect`, 반사 예산 = min(파츠 예측, 탄환 maxBounceCount), `_guidelineMaxRange` 캡)으로 꺾인 궤적 계산 → `LineRenderer` 표시.
  - 반사 예측기 미장착이면 `bounces=0`으로 첫 벽에서 멈추는 직선(직선 레이저는 파츠 없이 기본 상시 표시).

### 2) 파츠 7종 전 스테이지 배선
> "7종 파츠 전부 에셋+장착 / PlayerShooter 프리팹"

- 파츠 `.asset` 7종은 이미 `Assets/Data/WeaponParts/`에 존재 → **장착만 하면 됨**. 그런데 Stage1 Player엔 6종만 있고 **반사 예측기(Part_Reflect) 누락** → 반사 가이드라인이 안 보이던 원인.
- 전용 Player 프리팹이 없어 **각 스테이지 씬(Stage1~5 + 총합 테스트)의 Player `_equippedParts`에 7종 직접 장착**.
- ⚠️ 함정: 씬의 `List<WeaponPartSO>`에 `SerializedProperty`로 arraySize=7 설정 후 마지막(index 6) 원소를 넣으면 **저장 시 null로 떨어짐**(원소 순서를 바꿔도 마지막만 실패). → **리플렉션으로 `_equippedParts` 필드에 List를 직접 세팅**해 해결. 재오픈 검증 시 전 씬 count=7, null=0.
- 플레이 검증: Stage1에서 `reflectionEnabled=True, predictBounces=2, predictRange=6`, `BuildGuidelinePoints`가 벽에 맞고 되튕겨 3점(직선이면 2점) 생성 확인.

### 3) Player 프리팹화(공통 관리 리팩터링)
> "Player를 프리팹화해서 공통 관리하도록 리팩터링"

- 사전 조사: Player는 **외부 씬 참조가 전혀 없는 self-contained 루트**(tag=Player, child `Visual`). 적/UI/세이브는 전부 런타임 `tag`·`FindObjectOfType`로 조회 → 직렬화 참조 없음 → 교체 안전.
- `Assets/Prefabs/Player.prefab` 생성(`PrefabUtility.SaveAsPrefabAssetAndConnect`, Stage1 Player 기준·7종 파츠 포함) → Stage1 Player는 연결된 인스턴스로 전환.
- Stage2~5 + 총합 테스트의 기존 Player를 **프리팹 인스턴스로 교체**(각 씬 위치/회전/스케일 보존).
- 결과: 6개 씬 모두 `src=Assets/Prefabs/Player.prefab`, parts=7. **파츠 등 공통 설정은 프리팹 하나만 편집하면 전 스테이지 반영**.
