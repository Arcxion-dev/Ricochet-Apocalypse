## 처리 내용

### 1) 던전바닥 RuleTile (프롬프트 1)
- `walls_floor.png` 상단 3×3 블록 두 개(바닥 열16~48 / 벽 열144~176)를 표준 방향성 규칙으로 매핑.
- 산출물: `Assets/Resources/타일팔레트/던전바닥/Floor_RuleTile.asset`, `Wall_RuleTile.asset` (스크린샷으로 모서리/가장자리 검증).

### 2) 맵 에디터 Tilemap 오토타일 벽 개편 (프롬프트 3)
- **벽 시트 정규화**: `실제 사용할 리소스/{일반벽,강철벽,슬라임벽}.png`를 PPU 418로, 뒤죽박죽 슬라이스를 `ISpriteEditorDataProvider`로 균일 3×3(reading-order 0~8)로 재슬라이스(1타일=1칸).
- **벽 RuleTile 3종**: `Assets/Resources/타일팔레트/실제벽/{Normal,Steel,Slime}_Wall_RuleTile.asset` (colliderType=Grid, 표준 3×3 방향성).
- **레이어 헬퍼** `Assets/Editor/MapTileLayers.cs`: GridModule에 정렬된 Unity Grid("TileMap") 아래 `Tilemap_Floor` + `Tilemap_Wall_{Normal,Steel,Slime}` 생성/정렬. 벽 레이어 = TilemapCollider2D + Static Rigidbody2D + `ObstacleTypeMarker`(일반=Wall/강철=ArmoredWall/슬라임=Wall) + 슬라임엔 `ElasticWallMarker`, layer=8.
- **`MapEditorWindow` 개편**: 팔레트에 "타일" 브러시(바닥/일반/강철/슬라임) 추가. 씬 클릭 Paint=SetTile, Erase, Undo. 프리팹 브러시(적/스폰/나무·바위·수풀)는 병행 유지. "타일맵 레이어 생성/정렬" 버튼, "현재 타일로 외벽" 기능 추가.
- **장애물 스프라이트 교체**: WallPrefab_Bush/Rock/Tree → Bush_simple1_1/Rock1_1/Tree2 (각 1칸 크기로 PPU 조정).
- **데모 씬**: `Assets/Scenes/YJ_TestScene/Stage_TileDemo.unity`.

### 3) 지우개 개별 삭제 (프롬프트 4)
- `MapEditorWindow`에 토글 **"지우개: 현재 브러시 레이어만 삭제(바닥/벽/오브젝트 개별)"** 추가.
- OFF(기본): 해당 칸의 프리팹 + 모든 타일 레이어를 한 번에 삭제(기존).
- ON: 선택된 브러시가 가리키는 레이어만 삭제 — 타일 브러시=그 타일맵만, 프리팹 브러시=MapObjects 프리팹만. → 바닥/벽/오브젝트를 각각 개별 삭제 가능.

### 4) 장애물 VFX 연결 (프롬프트 4)
- 이름이 정확히 매칭되는 VFX 프리팹은 없어, `Assets/Prefabs/Effects/`의 테마 일치 VFX를 자식으로 부착:
  - `WallPrefab_Sandstorm` ← `Effects/Dust/Dust.prefab` (모래바람)
  - `WallPrefab_HeatHaze` ← `Effects/Fire/VFX_Fire.prefab` (아지랑이/열기)
- 각 벽 프리팹의 자식으로 VFX 프리팹 인스턴스(ParticleSystem) 부착, localPos 0.

## ⚠️ 재발 방지 메모
- **벽 타일맵에 CompositeCollider2D 금지.** 스크립트로 칠한 뒤 저장하면 컴포지트가 빈 지오메트리로 베이크되고 로드 후 자동 재생성되지 않아 런타임 충돌이 사라진다. TilemapCollider2D 단독(셀 단위 박스)로 사용할 것 — edit/play 모두 안정.
- 편집 시 **바닥과 각 벽 타입은 반드시 별도 레이어**에 칠해야 오토타일 이웃 인식이 맞음(에디터가 자동 분리).

## 추가 수정 (2026-08-06) — 적이 타일맵 벽 관통 문제
- 증상: 맵에디터로 벽(타일맵)·몬스터 배치 후 플레이하면 적이 벽을 그냥 통과.
- 원인: NavMeshPlus(CollectSources2d, UseGeometry=PhysicsColliders)는 수집한 콜라이더를 기본 '걷기 가능'으로
  처리한다. 프리팹 벽은 `NavMeshModifier`(Area=Not Walkable)가 있어 카브되지만, **타일맵 벽 레이어엔 이 모디파이어가
  없어** navmesh가 벽을 그대로 덮어 적이 통과. (Play 모드에서 벽 셀 SamplePosition이 navmesh에 덮임 → 재베이크해도
  모디파이어 없이는 그대로임을 확인해 특정)
- 수정:
  - `MapTileLayers.EnsureLayer`가 벽 레이어에 `NavMeshModifier`(OverrideArea=true, Area=1 Not Walkable)를 리플렉션으로
    자동 부착. `EnsureAllAligned`는 기존 레이어도 보수("타일맵 레이어 생성/정렬" 버튼으로 기존 씬 복구 가능).
  - `StageNavMeshBaker`: Tilemap 콜라이더 지연 생성 대비 Start 직후 1프레임(+물리 스텝) 뒤 재베이크 1회 추가.
  - 사용자의 테스트 씬 `Stage7`의 기존 벽 타일맵 3종에 모디파이어 적용 후 저장.
- 검증(Play): 수동 재베이크 없이 Normal 16/16셀, Slime 30/30셀 전부 navmesh 카브 → 적 우회. 관통 해소.
