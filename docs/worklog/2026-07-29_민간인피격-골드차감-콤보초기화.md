# 작업일지 — 2026-07-29 (담당: KimYunjae / Player 파트) · 민간인 피격 페널티(골드 차감 + 콤보 초기화)

Ricochet-Apocalypse · Unity 6000.3.18f1 · 2D · Legacy Input Manager · URP

이번 작업: 민간인 피격 시 **즉시 게임 오버(스테이지 실패)** 되던 처리를, **보상 재화(골드) 차감 + 콤보 초기화** 페널티로 완화. 차감 수치는 우선 **20**으로 설정.

> 결론 요약: `GameManager.OnCivilianHit()`이 더 이상 `StageFail()`을 호출하지 않는다. 대신 보유 골드에서 `_civilianHitPenalty`(기본 20)만큼 차감(`InventoryManager.Remove`가 보유량까지만 빼므로 음수 불가)하고, 콤보 상태(`_currentBulletKills`·`_bestCombo`)를 0으로 초기화한다. 스테이지는 계속 진행된다.

## 요청과 처리

### 1) 민간인 피격 = 실패 → 페널티로 전환
- `GameManager.OnCivilianHit()` 재작성:
  - 기존 `StageFail("민간인 피격")`(→ `SceneLoader.ReloadStage()`로 즉시 재시도) 호출 제거.
  - 보상 재화(골드) 차감: `InventoryManager.Instance.Remove(GoldDefinition, _civilianHitPenalty)`.
    `Inventory.Remove`는 보유 수량까지만 차감하므로 **골드가 음수로 내려가지 않는다**.
  - 콤보 초기화: `_currentBulletKills = 0`, `_bestCombo = 0`.
  - 이미 클리어/실패로 종료된 스테이지(`_stageEnded`)에서는 페널티 미적용(가드).
- 신규 인스펙터 필드 `_civilianHitPenalty = 20` (Header "민간인 피격 페널티"). 밸런싱 시 인스펙터에서 조정 가능.

### 2) 로그/주석 정합성 정리
- `BulletController.HandleObstacleHit`의 민간인 분기 로그: "스테이지 실패 처리" → "골드 차감 + 콤보 초기화 페널티". (탄환은 기존대로 `Die()`로 소멸, 흐름 자체는 불변)
- `GameManager` 클래스 헤더 주석: 실패 판정 목록에서 민간인 피격을 제외하고, 페널티 처리임을 명시.
- 디버그 컨텍스트 메뉴 라벨: "Debug/민간인 피격 (실패)" → "Debug/민간인 피격 (골드 차감 + 콤보 초기화)".

## ⚠️ 교훈 / 비고
- 보상 재화 = `Resources/Currency/Gold` 아이템(인벤토리). 스테이지 클리어 보상과 **동일한 재화**를 차감한다.
