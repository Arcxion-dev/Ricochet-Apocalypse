이번 작업: **무기 파츠 시스템**을 독립 파츠 방식으로 신설(손잡이/네뷸라이저/레이저/조준경 4종). 조준 가이드라인에 **사거리 상한(인스펙터)** + **벽 반사 궤적 예측선**을 넣고, **기본 레이저 조준선도 파츠로 전환**. **O키 파츠 토글 UI**로 파츠 효과를 켜고 끄며, **인벤토리/파츠 UI를 열면 `Time.timeScale=0`으로 게임 완전 정지**(적 멈춤) + 조준/격발 차단.

> 결론 요약: 파츠는 `WeaponEffectSO` 패턴을 본떠 `WeaponPartSO`(추상) + `WeaponStats`(집계 struct) + concrete 4종으로 만들고, `PlayerShooter._equippedParts` 리스트로 집계(**독립 파츠 → 후에 인벤토리 GunPart 연동**, 사용자 결정). 가이드라인은 실제 탄환과 같은 `CircleCast`+`Vector2.Reflect`로 반사 예측. **레이저·조준경 사거리는 합연산**. 정지는 두 timeScale 조작자(ChargeShotEffects) 충돌을 막기 위해 **PlayerShooter가 일원화**(정지 진입 시 `ChargeShotEffects.ForceStop()`으로 즉시 원복 후 0 세팅).

## 요청과 처리

### 1) 무기 파츠 시스템 (독립 파츠 → 인벤토리 연동 예정)
- `Assets/Scripts/Weapons/` 신설. `WeaponPartSO`(추상, `Contribute(ref WeaponStats)`) + `WeaponStats`(집계 struct: swayMultiplier / slowScaleMultiplier / laserEnabled / laserRange / predictBounces / predictRange).
- concrete 4종(각 `[CreateAssetMenu]`):
  - `GripPartSO`(손잡이): `swayMultiplier`(기본 0.5) → 호흡 흔들림 진폭 곱.
  - `NebulizerPartSO`(네뷸라이저): `slowScaleMultiplier`(기본 0.6) → 차징 슬로우 강화.
  - `LaserSightPartSO`(레이저): 가이드라인 on + `range`(직선 사거리).
  - `ScopePartSO`(조준경): `extraBounces`(반사 예측 수) + `extraRange`(사거리 추가). 레이저와 **합연산**.
- 에셋: `Assets/Data/WeaponParts/Part_{Grip,Nebulizer,Laser,Scope}.asset`.

### 2) 조준 가이드라인 (사거리 캡 + 반사 궤적 예측) — `PlayerShooter`
- 기존 `_laserLength`(직선 20, 벽 관통) 제거. `BuildGuidelinePoints()`가 실제 탄환(`BulletController`)과 같은 **`Physics2D.CircleCast` + `Vector2.Reflect`** 로 벽 반사를 예측해 꺾인 LineRenderer 경로를 만든다.
- **사거리 상한 `_guidelineMaxRange`(인스펙터)** 로 캡. 유효 사거리 = `laserRange + predictRange`(합연산) → 상한 클램프.
- 벽 레이어는 인스펙터 미설정 시 **탄환 프리팹의 `WallLayerMask`에서 자동 취득**(탄환과 동기화). `maxBounces=0`이면 첫 벽에서 멈추는 직선 가이드.
- **기본 레이저가 파츠로 전환**: 레이저/조준경 파츠가 없으면 가이드라인 미표시(`_laser.enabled=false`).

### 3) 파츠 효과 적용 지점
- 손잡이 → `ComputeBreathDir`에서 `_breathAmplitudeDeg * _stats.swayMultiplier`.
- 네뷸라이저 → `ChargeShotEffects`에 `SetSlowScaleMultiplier()` + `EffectiveSlowScale`(RampCharge 목표 타임스케일에 반영).
- `RecomputeParts()`가 장착(그리고 활성) 파츠를 집계 → 연출에 전달.

### 4) O키 파츠 토글 UI (`WeaponPartsUI`) + UI 정지
- `InventoryUI`와 같은 런타임 uGUI(부트스트랩 싱글톤, DontDestroyOnLoad). **O키** 좌상단 패널, 현 씬 PlayerShooter의 `EquippedParts` 나열, 파츠별 **ON/OFF 버튼**(초록/빨강). 장착 리스트에서 빼지 않고 효과만 on/off(`_disabledParts` 셋).
- PlayerShooter 공개 API: `EquippedParts / IsPartActive / SetPartActive / TogglePart`(+ 기존 `EquipPart/UnequipPart`, 인벤토리 연동 진입점).
- **UI 정지**: `InventoryUI.IsOpen || WeaponPartsUI.IsOpen` → `UpdateUiPause`가 `Time.timeScale=0`(적 완전 정지) + 조준/격발 차단, 닫히면 1 복귀. 진입 시 차징 중이면 `ExitBreath` + `ChargeShotEffects.ForceStop()`(즉시 원복)로 슬로우 코루틴과 충돌 방지. 씬 전환 stuck 방지 Awake 안전장치.

### 5) 씬 배선
- Stage1/2/3 각 PlayerShooter(host "Player")의 `_equippedParts`에 **4종(레이저·조준경·손잡이·네뷸라이저) 배선 + 저장**(MCP `script-execute`로 일괄).

## ⚠️ 교훈 / 비고
- **신규 스크립트의 `RuntimeInitializeOnLoadMethod` 부트스트랩은 컴파일 직후 진입한 플레이 세션에서 안 뜰 수 있음** → 플레이 종료 후 **재진입(새 도메인)** 하면 정상. (WeaponPartsUI가 첫 세션에 count=0이던 원인.)
- 가이드라인 반사 예측은 벽 레이어(Wall)만 대상. 철갑탄 관통 등 탄종별 특성은 미반영(단순화) — 필요 시 선택 탄종의 maxBounce 반영 확장 여지.
- 파츠 세기(swayMultiplier/slowScaleMultiplier/range/extraBounces/extraRange)와 가이드라인 상한(`_guidelineMaxRange`)은 에셋/인스펙터로 조정.
- **후속**: 인벤토리 `ItemDefinition`(GunPart)이 `WeaponPartSO`를 참조하도록 연동 → 인게임 획득·장착 흐름. (지금은 인스펙터/O키 토글만.)
- 상세 현황은 CC 메모리 `weapon-parts-system`에도 기록. 세션 시작 시 실수로 main에 있던 커밋들을 Player 브랜치로 이동 후 이번 작업 진행([[worklog-index]] 참고).
