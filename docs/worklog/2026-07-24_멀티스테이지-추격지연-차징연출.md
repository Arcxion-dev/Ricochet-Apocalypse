## 요청과 처리

### 1) 멀티 스테이지 (씬 파일 3개 분리)
- `Assets/Scenes/Stage1/2/3.unity` 생성 — 모두 `Stage.unity`를 `AssetDatabase.CopyAsset`으로 복제. **바닥(Background_Floor)+장애물(WallPrefab×4)이 동일 → 기존 `Stage_NavMesh.asset`을 그대로 공유(스테이지별 재베이크 불필요).**
- 레이아웃: **플레이어 하단(0,-3)**, **적 상단 분포** — Stage1 3기 / Stage2 4기 / Stage3 5기(난이도 상승). 부족한 적은 기존 적 복제, 남으면 파괴로 수 맞춤.
- 카메라: 전 스테이지 pos(0,1.5,-10)/orthographicSize 7 → 하단 플레이어 + 상단 적 전장 전체 프레이밍.
- `SceneLoader` 수정: `SceneNames.Stages = {"Stage1","Stage2","Stage3"}` 배열 기반. `LoadStage(index)`가 배열에서 씬을 고르고 인덱스가 넘으면 `LoadResult()`. `ReloadStage`/`ResetStage`도 현재 index 씬 사용. `IsStageScene(name)` 헬퍼 추가(→ `SceneNavigatorUI`가 사용).
- Build Settings 순서: **Title, Stage1, Stage2, Stage3, Shop, Result**. 구 `Stage.unity`는 파일만 남기고 Build Settings에서 제외.
- 각 스테이지 GameManager `_goToShopOnClear=false` → 클리어 시 `LoadNextStage()` 직행. *(주의: GameManager는 DontDestroyOnLoad 싱글턴이라 최초 로드 씬의 설정만 유효 → 3개 모두 false로 통일.)*

### 2) 추격 지연 (플레이어 첫 발사 후 N초) — 핵심 정정
- 사용자 정정: 적이 총을 쏘는 게 아니라 **플레이어가 첫 발을 쏘면 지연 후 적이 추격 시작**. 적 사격/피해 로직은 만들지 않음.
- `GameManager`: `_enemyChaseDelay`(기본 1f, 인스펙터 조정) + `EnemiesCanChase` 프로퍼티. `RegisterShot()` 첫 호출에 `WaitForSecondsRealtime(_enemyChaseDelay)` 코루틴 무장 → true. `ResetStageState()`에서 false 리셋 + 코루틴 정지(스테이지 넘어갈 때마다 다시 "발사 전 정지").
- `EnemyAIModule.Update()`: `SetDestination` 직전에 `if (GameManager.Instance != null && !GameManager.Instance.EnemiesCanChase) return;` 가드 1줄.

### 3) 차징 사격 연출 (신규 `ChargeShotEffects.cs`)
- 기존 3단계 조작 유지(좌클릭=조준고정, 재좌클릭=발사, 우클릭=취소) + 연출만 얹음. `PlayerShooter`가 3콜백 구동: `EnterBreath→BeginCharge()`, `TryFire 성공→Fire()`, 우클릭취소/탄없음→`Cancel()`. `TryFire`는 bool 반환으로 변경.
- **조준 고정 시**: 슬로우모션(`Time.timeScale`→0.35, `fixedDeltaTime` 동기화) + 직교 확대(orthoSize −1.2) + URP **런타임 생성 Global Volume**(Bloom+Vignette override, 씬 배치 불필요 · 카메라 `renderPostProcessing` 자동 on) 상승. 조준선 고정+랜덤 흔들림은 기존 `ComputeBreathDir`(Perlin sway) 재사용.
- **발사 시**: 화면 흔들림 + **timeScale 1.2배 급가속(오버슈트) 후 1.0 복귀**. 램프는 `unscaledDeltaTime` 기반. `OnDisable`에서 timeScale=1 강제 복원(씬 전환 안전장치).
- 카메라 흔들림은 `CameraPanController.ExternalShakeOffset`(LateUpdate 가·감산 훅) 통해 주입 → 팬 위치와 충돌 없음. 호흡 중 연출이 있으면 카메라 팬/줌 잠금.
