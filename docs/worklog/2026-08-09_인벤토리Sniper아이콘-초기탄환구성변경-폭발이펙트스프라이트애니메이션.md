## 1) 인벤토리 무기 아이콘 = Sniper1
- `Assets/Resources/UI/InventoryScreen.prefab`의 로드아웃 → `WeaponBox` → **WeaponIcon** Image가 스프라이트 없이 시안 플레이스홀더 틴트만 있던 상태.
- `m_Sprite`를 **Sniper1**(`guid 9cd0e7df…`, single 스프라이트 `fileID 21300000`)로 배선. `m_Color`를 흰색으로(실제 아트 색 표시), `m_PreserveAspect: 1`(80×80 박스에서 찌그러짐 방지).
- 이어서 아이콘 **Scale (1,1,1)→(10,5,1)**(가로 10·세로 5배), 상단 피벗(0.5,1) 기준으로 커지므로 **anchoredPosition.y −38 → +100**으로 WeaponBox(높이 200) 세로 중앙에 맞춤.
- `Sniper1.png`는 이미 Sprite(Single)로 임포트돼 있어 추가 임포트 변경 없음.

## 2) 첫 스테이지 초기 탄환 구성 변경
- 지급은 `PlayerShooter.Start()`가 `_startingBullets` 리스트의 각 항목을 인벤토리에 **1개씩** 추가하는 방식(스테이지1 한정, `SceneLoader.CurrentStageIndex == 0`).
- `Assets/Prefabs/Player.prefab`의 `_startingBullets`를 교체 — 기본탄을 2번 넣어 2개가 되게:
  - 기본탄 ×2 (`BItem_Basic`), 철갑탄 ×1 (`BItem_1_ArmorPiercing`), 분열탄 ×1 (`BItem_3_Split`), 화염탄 ×1 (`BItem_8_Burn`).
  - 기존 유도탄(`BItem_5_Homing`)은 제거. 애셋은 `Assets/Resources/BulletItems/`의 `BulletItemDefinition`.

## 3) 폭발 이펙트 스프라이트 애니메이션
- 리소스: `Assets/Resources/실제 사용할 리소스/VFX/폭팔이펙트.png`. Default 텍스처였던 것을 **Sprite**로 전환 후, 사용자가 **Multiple 모드로 슬라이스**(폭팔이펙트_0 … 512×368, 다수 프레임).
- 신규 `Assets/Scripts/Effects/ExplosionSpriteEffect.cs`: 파티클/Animator 없이 **코드 구동 프레임 애니메이션**.
  - `Resources.LoadAll<Sprite>("실제 사용할 리소스/VFX/폭팔이펙트")`로 프레임 전부 로드 후 **이름 접미사 숫자(`_N`)로 정렬**(LoadAll 순서 미보장 대응), 한 번 로드해 static 캐시.
  - `Spawn(position, worldSize, duration=1.2f)`로 지점에 1회 생성 → 경과 비율을 프레임 인덱스로 환산해 순서대로 재생, **1.2초**에 마지막 프레임까지 간 뒤 스스로 파괴. 첫 프레임 기준으로 반경×2 지름에 맞춰 스케일(비율 유지), `sortingOrder 500`.
- 연동(둘 다 `Spawn` 호출):
  - 폭발탄 `Bullets/Effects/ExplosiveEffectSO.cs` `Detonate` → `Spawn(pos, explosionRadius*2, 1.2f)`(기존엔 시각 효과 없이 대미지만).
  - 수류탄/폭격지원 `PlayerShooter.cs` `UseItemAt`(Grenade/Airstrike 분기) → `Spawn(point, effectRadius*2, 1.2f)`. 섬광탄은 요청 범위 밖이라 기존 `PlayItemVfx`(EffectHandler) 유지.
- 참고: AnimationClip+Animator 프리팹 대신 코드 프레임 재생을 택함(1회성·풀링 없이 타이밍/크기 제어가 단순·정확). 필요 시 AnimationClip 애셋 방식으로 전환 가능.
