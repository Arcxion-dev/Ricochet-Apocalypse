## 1) 갇힌 스폰 재배치
- 전 40스테이지 스캔 → **진짜로 못 움직이는 맵은 Stage_23 하나**. 스폰 `(14,1)`이 좌우 둘 다 벽·위만 열림. **모바일은 좌/우 이동만** 가능하므로 세로만 뚫린 스폰=트랩. `(14,1)→(9,6)`(우측 열림)으로 재배치.
- 신규 `Assets/Editor/PlayerSpawnFixer.cs`(Tools/Ricochet/갇힌 플레이어 스폰 재배치): 벽 타일맵 3종 `HasTile` + `OverlapBox`(layer 8)로 blocked 판정. **좌우 둘 다 막힘 / 완전 둘러싸임 / 열린영역<6**이면 바닥중앙에서 가까운 "좌 또는 우가 열린 넓은 칸"으로 Player(+PlayerSpawnMarker) 이동. 나머지 39맵 무변경.
- **삽질 메모**: 처음엔 맵 정의 표만 보고 Stage_23/35가 갇혔다 추정했으나, 실제 씬에선 스폰칸이 열려 있었음(표 행 오독). 씬 실측(HasTile/Overlap)으로 재조사해 "좌우 이동만 되는 모바일" 관점의 수평 갇힘으로 특정.

## 2) 인게임 BGM + BGM/SFX 볼륨 배선
- 기존 버그: `GameSettings`가 BGM/SFX 값만 PlayerPrefs 저장하고 실제 사운드에 미반영(마스터만 `AudioListener.volume`). `SoundManager`도 미구독.
- 수정: `SoundManager`가 `GameSettings.Changed` 구독 → `SetSfxVolume(SfxVolume)`+`SetMusicVolume(BgmVolume)`로 **각각 독립 반영**(설정 UI엔 이미 Master/BGM/SFX 슬라이더 존재 → 배선만).
- BGM 재생: `The_Unseen_Aim.wav`를 `ThirdParty/Sound → Resources/Sound`로 이동(GUID 보존 rename), `SoundManager.PlayMusicClip(clip,loop)` 오버로드 추가, 신규 `StageBgm` 부트스트랩이 씬 이름 "Stage" 시작 시 루프 재생·아니면 정지.
- 검증(플레이): `clip=The_Unseen_Aim playing=True loop=True`, BGM=0.3/SFX=0.2 설정 시 `musVol=0.3/sfxVol=0.2` 독립 반영.

## 3) 설정 → 메인 메뉴 버튼
- `SettingsUI`에 "메인 메뉴로" 버튼: `Time.timeScale=1` 복구 후 `SetVisible(false)`→`SceneLoader.LoadTitle()`(스테이지 인덱스 리셋+SceneTransition). 기존 AddButton 패턴 재사용.

## 4) 인벤 닫기 버튼 X
- `InventoryUI.EnsureCloseButton`: "✕"(U+2715, NotoSans 미포함→두부박스=네모로 보임)를 **ASCII "X" + UITheme.Bold** 폰트로 교체, 배경 알파 0.16(투명)으로 네모 느낌 제거. 검증: `X text='X' font='NotoSansKR-Bold SDF' bgAlpha=0.16`.

## 5) 탄환 교체 슬롯 동적화
- 원인 2곳: ① `PlayerShooter.RebuildChoices`가 `_choices`를 `MaxSelectableBullets(5)`로 캡 → 5종 초과 누락. ② `RevolverCylinderUI`가 프리팹 고정 약실 배열만큼만 표시(`Min(choices, ChamberCount)`).
- 수정 ①: RebuildChoices의 `else if (< MaxSelectableBullets)` → `else`(모든 종류 수용). 숫자키 1~5는 유지.
- 수정 ②: 약실을 **런타임 풀**로 동적 생성 — 직렬화 약실을 최소개수 시드로 두고 첫 약실을 템플릿 복제해 `_active=Max(직렬화 수, 탄종 수)`까지 확장. 모든 `_chambers[]`/`ChamberCount` 순회를 `_pool`/`_active`로 전환. 회전·스냅·탭·엣지페이드·루프(Mod)는 그대로라 전체 탄환 순환 가능. 약실 수 변화 시 12시로 스냅.
- 검증(플레이): 9종 주입 → `choices=9, _active=9(프리팹 5→동적 9), _filled=9`. 옛 상한 밖 9번째(index 8) 선택·착좌 정상, 스크린샷상 약실 다수 정상 표시. 세이브/씬 오염 없음.
