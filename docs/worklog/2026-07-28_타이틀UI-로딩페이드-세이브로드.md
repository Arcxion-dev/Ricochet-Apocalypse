## 요청과 처리

### 1) 타이틀 UI (FreeDemo.png → 씬 실배치)
> "FreeDemoUi로 … 타이틀에 Ui를 만들고"

- `FreeDemo.png`(256×256, Sprite Mode Single)를 **Multiple로 재임포트**하고, 알파 컬럼 스캔으로 대나무 패널(PLAY/SETTINGS/EXIT 텍스트가 그려진 부분)만 정확히 잘라 `TitlePanel` 스프라이트 생성. 우측 알약버튼(x139~)은 컬럼 프로파일에서 x136~138 빈 열을 경계로 제외 → 최종 rect **(4,22,132,117)**. FilterMode=Point, mipmap off(픽셀아트 선명).
- `Title.unity`에 실제 Canvas/Image로 배치(`TitleCanvas`). 라벨 텍스트는 스프라이트에 baked이므로 **그 위에 투명 버튼(alpha 0, raycastTarget=true)** 3개(PlayButton/SettingsButton/ExitButton)를 올려 이미지와 100% 동일한 외형.
- `TitleMenuUI.cs`: 자식에서 이름으로 버튼을 찾아 클릭 연결. PLAY=현재 진행 스테이지 로드(세이브 있으면 자동 이어하기), SETTINGS=설정 패널, EXIT=종료(에디터는 플레이 정지). 타이틀 진입 시 세이브 있으면 자동 `Load()`.

### 2) 오버레이 로딩창 + 씬 페이드
> "시작할 때 Loading 창 및 씬 Fade in Out" / "오버레이 방식으로 하고 작업 진행해"

- `SceneTransition.cs`(DontDestroyOnLoad 싱글턴, sortingOrder 5000): 페이드아웃 → 로딩 패널(LOADING + 진행바 fillAmount + %) → `SceneManager.LoadSceneAsync`(0.9까지 대기, `allowSceneActivation` 보류) → 페이드인. 페이드/타이머는 **unscaled**(TimeScale 0에도 정상). 부팅 시 인트로 로딩+페이드인.
- `SceneLoader.LoadScene`이 `SceneTransition.Instance`가 있으면 그걸 경유하도록 수정(없으면 동기 로드 폴백) → **모든 씬 전환에 자동 적용**. 진행도 주입용 `SetCurrentStageIndex(int)` 추가.

### 3) 세이브/로드 + 설정
> "세이브/로드 시스템까지" / 저장 범위 = 진행도+인벤토리+파츠+설정값

- `SaveManager.cs`: `persistentDataPath/save.json`에 진행도(현재/최고 스테이지), 인벤토리(id·분류·수량), 활성 무기파츠명 저장(JsonUtility). **스테이지 진입 시 GameManager.OnSceneLoaded에서 자동 저장**, 타이틀 진입 시 자동 로드(이어하기). 인벤토리 복원은 Resources의 `ItemDefinition` 우선, 없으면 런타임 정의로 대체(수량 보존).
- `GameSettings.cs`: 마스터/BGM/SFX 볼륨·전체화면·해상도를 PlayerPrefs로 영속화. 마스터→`AudioListener.volume`, 전체화면/해상도→`Screen` API 실제 반영. BGM/SFX는 값만 저장(추후 AudioMixer 연결 예약).
- `SettingsUI.cs`: 런타임 생성 패널(`Show/Hide`). 볼륨 슬라이더 3개 + 전체화면 토글 + 해상도 ◀▶ + 세이브 삭제 + 닫기.

### 4) (플레이 후) 버그 3종 수정
> "설정창 아래가 살짝 짤리네 … 세이브삭제해도 스테이지1로 안돌아와 … 스테이지2 치트 UI 클릭이 안되네"

- **설정창 하단 잘림**: 패널에 `ContentSizeFitter`(vertical PreferredSize) 추가 → 내용 높이에 맞춰 자동 크기·중앙 정렬. `닫기`까지 다 보임.
- **세이브 삭제해도 진행도 유지**: `SaveManager.DeleteSave`가 파일만 지우고 `CurrentStageIndex`는 그대로였음. 이제 삭제 = **파일 삭제 + 진행도 0 + 인벤토리 비우기**, SettingsUI 버튼은 이어서 `LoadTitle()`로 타이틀 복귀.
- **스테이지2 치트 UI 클릭 불가(핵심)**: 원인은 **Stage2 씬에 EventSystem이 아예 없음**(Stage1엔 있음). uGUI는 EventSystem 없으면 어떤 UI도 클릭 불가. → 항상 살아있는 `SceneTransition`이 `sceneLoaded`마다 EventSystem을 보장(`EventSystem.current==null`일 때만 생성, 중복 없음).

## ⚠️ 교훈 / 비고
- **씬에 EventSystem이 없으면 그 씬의 모든 uGUI 클릭이 먹통**. 스테이지 씬마다 유무가 달라 Stage1은 되고 Stage2는 안 되는 증상이 났다. → 영속 매니저가 씬 로드마다 보장하는 방식으로 회귀 방지.
- 로딩은 "오버레이(표시 방식) vs 전용 씬(메모리 전략)"이 대립 개념이 아님. 2D·가벼운 씬이라 오버레이로 확정.
- 스프라이트 시트에서 특정 요소만 정확히 잘라낼 땐 **알파 컬럼 프로파일 스캔**으로 빈 열(gap) 경계를 찾는 게 확실(눈대중 rect는 인접 요소가 새어들어옴).
- 미배치: 각 스테이지 씬 파일 자체엔 여전히 EventSystem이 없음(런타임 자동 보장으로 커버). 좌상단 dev용 SceneNavigatorUI 오버레이는 그대로 유지.
- BGM/SFX 볼륨은 값 저장만(실제 믹싱은 AudioMixer 도입 시 연결) — 사용자 "일단 UI 위주" 요청 범위.
