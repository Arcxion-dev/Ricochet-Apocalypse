## 요청과 처리

### 1) 수풀/모래바람/아지랑이 위 적 은신
> "몬스터가 위치한 경우 … 보이지 않도록(은신) … 장애물에 총을 쏴서 맞혔을 경우 피격 … 장애물 밖으로 나오면 은신 풀림"

- 신규 `Assets/Scripts/Modules/Enemy/StealthModule.cs`:
  - 주기(0.15s)마다 적 중심에서 `Physics2D.OverlapCircleNonAlloc`(Wall 레이어) → `BulletController.ResolveTargetType`로 Bush/Sandstorm/HeatHaze 판정 → `SpriteRenderer.enabled` on/off(GC 없는 정적 버퍼 사용).
  - 장애물 밖으로 나오면 자동 해제. `OnDisable`에서 렌더러 복구(사망/재사용 잔상 방지).
- `EnemyController.Awake`가 StealthModule을 **자동 부착**(HeadshotModule과 동일 패턴) → 프리팹 개별 수정 없이 모든 적에 적용.
- **피격**: 은신은 렌더러만 끄고 콜라이더는 유지. 이 3종 장애물은 총알을 **관통**(`DetermineHitResult`→Penetrate)시키므로, 장애물에 쏜 관통 총알이 은신 적 콜라이더에 그대로 명중 → 별도 릴레이 코드 없이 "장애물을 쏘면 은신 적 피격" 성립.
- HitFeedback 피격 플래시는 `color`만 바꿔 꺼진 렌더러와 충돌하지 않음(꺼진 렌더러는 색과 무관하게 안 보임).

### 2) 은신 장애물 3종 NavMesh 보행 가능화
> (질문 응답) "보행 가능으로 변경"

- 원인: Bush/Sandstorm/HeatHaze 프리팹 `NavMeshModifier`가 `m_Area:1`(비보행)이라 추격 적이 그 위에 올라설 수 없어 은신이 발동 못 함.
- 조치: 3종 프리팹 `m_Area 1→0`(보행 가능, `m_OverrideArea:1` 유지). 추격 적이 수풀에 들어가 능동적으로 은신.
- ⚠️ 정적 배치 Stage 씬은 NavMesh **재베이크 필요**(사용자가 직접 재베이크함). 런타임 리셋(`MapResetController`) 경로는 자동 재베이크.

### 3) 화염 탄환이 관통한 풀숲 제거
> "화염탄환이 부쉬를 통과할 경우 부쉬들을 제거하는 기능"

- `BulletController.HandleObstacleHit`에 속성 기반 처리 추가: `targetType == Bush && Data.element == ElementType.Fire`이면 폭발 이펙트 재생 후 `Destroy(obstacle.gameObject)`.
- 풀숲은 관통 대상이라 총알은 계속 진행하고 풀숲만 제거됨 → 안에 은신했던 적이 드러남(StealthModule이 0.15s 내 재판정해 은신 해제).
- 속성 기반이라 화염 전용탄뿐 아니라 **모든 Fire 속성 탄환**에 적용.

### 4) 화염/얼음/전기 속성 부여 검증 (코드 변경 없음)
- 흐름 정상: `BulletSO.element` → `BulletController.HandleEnemyHit`(`Data.element` 전달) → `EnemyController.OnBulletHit` → `AttributeModule.GetDamageMultiplier(weaknessTable)`.
- 데이터: Bullet_8 화염(element 1) / Bullet_9 냉기(6) / Bullet_7 전기(5). Enemy_Fire·Ice·Electric의 weaknessTable 배선 정상(예: Fire 적 = 냉기 x2 / 물 x1.5 / 화염 x0.5, Ice 적 = 화염 x2 / 냉기 x0.5, Electric 적 = 대지 x2 / 전기 x0.5). 트레일 색상도 속성별 매핑.
- 결론: **속성 부여 기능 정상 작동**.
