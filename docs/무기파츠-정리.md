# 무기 파츠(Weapon Parts) 정리

Ricochet-Apocalypse · `Assets/Scripts/Weapons/` · 작성일 2026-07-28

## 구조 개요

- 모든 파츠는 `WeaponPartSO`(추상 ScriptableObject)를 상속하고, `Contribute(ref WeaponStats)`에서 자기 효과를 **집계 구조체 `WeaponStats`에 더한다**. (탄환 효과 `BulletEffectSO`와 동일한 데이터 주도 패턴)
- `PlayerShooter.RecomputeParts()`가 `WeaponStats.Default`에서 시작해 장착 파츠를 순회하며 `Contribute`를 호출해 `_stats`를 만든다. 이 `_stats`가 조준선·호흡 흔들림·차징 슬로우·헤드샷·대미지에 반영된다.
- **활성/비활성 토글**: 파츠는 장착 리스트에 남긴 채 효과만 껐다 켤 수 있다(`SetPartActive`/`TogglePart`, `_disabledParts`에 있으면 집계 제외). 게임 중 **O 키 UI**(`WeaponPartsUI`)로 토글한다.
- 장착/해제: `EquipPart`/`UnequipPart`(추후 인벤토리 GunPart 연동 진입점).

`WeaponStats` 필드(파츠가 채우는 값): `swayMultiplier`, `slowScaleMultiplier`, `laserEnabled`, `laserRange`, `reflectionEnabled`, `predictBounces`, `predictRange`, `headshotMultiplierBonus`, `guaranteedHeadshotChain`, `damageMultiplier`.

## 파츠별 역할

| 파츠 | 에셋 메뉴 | 효과 | 핵심 값(기본) | 중첩 |
|---|---|---|---|---|
| **손잡이 (Grip)** `GripPartSO` | Weapon/Parts/손잡이 | 조준 시 **호흡 흔들림(sway) 진폭 감소** | `swayMultiplier` 0.5 (−50%) | 곱연산 |
| **네뷸라이저 (Nebulizer)** `NebulizerPartSO` | Weapon/Parts/네뷸라이저 | 조준(차징) 시 **슬로우모션 강화**(더 느리게) | `slowScaleMultiplier` 0.6 | 곱연산 |
| **강선 (Rifling)** `RiflingPartSO` | Weapon/Parts/강선 | **탄환 대미지 강화**(강화도 레벨당 증가). *기본 장착* | `damagePerLevel` 0.25 → 레벨당 +25% | 곱연산 |
| **조준경 (Scope)** `ScopePartSO` | Weapon/Parts/조준경 | **헤드샷(크리티컬) 대미지 배수 증가**. (조준선은 안 그림) | `headshotBonus` 0.2 (+20%) | 합연산 |
| **텅스텐 탄환 (Tungsten)** `TungstenPartSO` | Weapon/Parts/텅스텐 탄환 | 자연(확률) 헤드샷 명중 시 **다음 명중을 확정 헤드샷**으로. (무한 연쇄 아님) | 플래그 on | — |
| **레이저 (Laser Sight)** `LaserSightPartSO` | Weapon/Parts/레이저 | **직선 조준 가이드 사거리 증가**. (직선 레이저 자체는 파츠 없이 기본 상시 표시) | `range` +8 유닛 | 합연산 |
| **반사 예측기 (Reflection Sight)** `ReflectionSightPartSO` | Weapon/Parts/반사 예측기 | **벽 반사 궤적(꺾이는 예측선) 표시** + 반사 예측 사거리 추가 | `bounces` +2, `extraRange` +6 유닛 | 합연산 |

> 참고: `강선`은 `DisplayName`에 강화도/증가율을 표기하고(`강선 +N (데미지 +NN%)`), `PlayerShooter.UpgradeRifling()`로 한 판 동안 누적 강화된다.

## ✅ 총알 반사 경로 가이드라인 파츠 — 구현되어 있음

**결론: 구현되어 있다.** 담당 파츠는 **반사 예측기(`ReflectionSightPartSO`)**이고, 실제 렌더링은 `PlayerShooter`가 한다.

- **직선 가이드는 파츠 없이 기본 상시 표시**(`LineRenderer` 레이저). 첫 벽에서 멈추는 순수 직선이다.
- **반사 예측기 파츠를 장착해야만** 조준선이 벽에 튕겨 꺾이는 예측 궤적을 그린다. 미장착이면 `bounces=0`으로 직선만.

동작 경로(코드 위치):
1. `ReflectionSightPartSO.Contribute` → `reflectionEnabled=true`, `predictBounces += bounces`, `predictRange += extraRange` (`Assets/Scripts/Weapons/ReflectionSightPartSO.cs`).
2. `PlayerShooter.UpdateLaser` (`PlayerShooter.cs:915`) → `_stats.reflectionEnabled`면 반사 횟수/예측 사거리를 사용, 사거리는 **상한 `_guidelineMaxRange`(기본 14유닛)로 캡**.
3. `PlayerShooter.BuildGuidelinePoints` (`PlayerShooter.cs:963`) → **실제 탄환과 동일한 규칙**으로 예측:
   - `Physics2D.CircleCast`(탄환과 같은 벽 레이어·반지름) + `Vector2.Reflect`(법선 반사).
   - 반사 예산 = `min(파츠 예측 횟수, 선택 탄환 maxBounceCount)` — 실제 탄환보다 더 튕기게 그리지 않음.
   - 관통(철갑탄+벽, 풀숲/모래)·파괴형·민간인 소멸까지 실제 탄환 반응을 반영해 궤적을 그린다.
   - 결과 점들을 `LineRenderer`에 세팅해 꺾인 가이드라인으로 표시.

즉 "총알이 반사되는 경로를 가이드라인으로 표시"하는 기능은 **반사 예측기 파츠 + `PlayerShooter.BuildGuidelinePoints`** 조합으로 완성되어 있으며, 조준선과 실제 탄환의 튕김 위치가 일치하도록 레이어·반지름·바운스 한도를 맞춰 두었다.

## 미비/참고
- 파츠의 **인벤토리(GunPart 카테고리) 연동**은 진입점(`EquipPart`)만 열려 있고 실제 UI 장착 흐름은 미배선(현재는 코드/디버그 O키 UI로 on/off).
- 각 파츠 `.asset` 실물은 `Assets/Data/WeaponParts/`(예: `Part_Reflect.asset`)에 만들어 `PlayerShooter`의 장착 리스트에 넣어 사용.
